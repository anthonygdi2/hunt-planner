# Reference videos (Kusnier)

Which of Kusnier's YouTube videos (channel [@Kusnierr](https://www.youtube.com/@Kusnierr/videos)) have hunt data worth reading into `REFERENCE` (`src/data/reference.json`), and which are done. Listed October 24, 2026 from all 730 videos on the channel, newest first.

How to use it:

- Run `/reference-batch` in Claude Code (`.claude/skills/reference-batch/SKILL.md`): it works down the **Queue** from the top (newest first), ten videos per batch, reading each "Results" frame in the in-app browser. `node tools/reference/batch.js embed` adds the records to `tools/reference/readings.json`, regenerates `REFERENCE` in `src/index.html`, and changes the rows from `todo` to `done <date>`. By hand: add a record to `readings.json`, run `node tools/reference/generate.js`, and mark the row.
- Post-rebalance means published on or after June 18, 2026 (the vocation rebalance went live mid-June). Older entries get `postRebalance: false`.
- Since mid-2026 his guides open with a results slide from about 0:04 to 1:30 (0:12 is a safe frame): a summary table (his "Expected Loot (market values)" is balance per hour, usually rounded down) and the Hunt Analyser with the kill list. Older guides show a results table and the analyser a minute or two in.
- `node tools/reference/refresh-videos.js` checks the channel for new uploads: likely solo guides go to the top of the Queue as `todo`, duo/team showcases to Maybe, "Roast My Hunt" reviews to the skipped counts, and anything else to the Queue as `check` (decide by hand: `todo`, or delete the row and add it to a skipped count). It keeps every status and updates # (position on the channel, newest first) and Age. Age is as of October 25, 2026.
