Tiers and hazard

Each tier tile always shows its letter, so color is never the only cue. Text on every tile is --on-gold (#1a1408), 7.7:1 or better.

Sizes and layout

  • Any tap target: 44 px minimum. Main actions 52 px. Tab bar items 56 px.
  • Phone design width 390 px; works down to 320.
  • Desktop: content max 1280 px. The inputs column is 340–420 px; the plan takes the rest. Below about 900 px the columns stack.
  • Borders: 1 px default, 2 px for “open”, “next move” and selected.
  • Focus: 3 px --focus outline, 2 px offset.
  • Motion: none needed. If added, 150 ms, and none under prefers-reduced-motion.
