Components

Plain HTML and CSS, no framework. Every interactive part is a real button, link, input or select. Flip the Theme tweak to see light.

Chip

  • Set: label in muted, value in bold, solid border. Not set: dashed border, “+ name”. Open: 2px accent border, aria-expanded true.
  • Tapping opens its inline editor right below the chip row. Only one open at a time.

Buttons

  • Primary (gold) is only for your next move: Free, Save hunt, Show my plan, Picked A. One per screen.
  • Solid closes or confirms an editor (Done, Back to plan). Secondary for everything else. Dashed adds something new.
  • Icon-only buttons always carry an aria-label.

Segmented, switch, stepper

4
  • Segmented: one choice, aria-pressed on each button, selected is filled with --text. Arrow keys move between options.
  • Switch: role=switch, knob position plus color. Stepper: tokens 0–10, output is aria-live.
